Création d'Applications SCCM
Distribution logicielle — EXE / MSI
AApplication EXE (script)
01
Sélectionner « Spécifier manuellement », cliquer Suivant.
02
Définir le nom et la version du logiciel, cliquer Suivant.
03
Saisir les informations (nom, icône) visibles dans le Centre Logiciel.
04
Créer un Type de déploiement → Ajouter → Programme d'installation de script.
05
Entrer le chemin UNC de l'exécutable. Ajouter /S pour installation silencieuse si nécessaire.
06
Paramétrer la règle de détection (ex : présence de Notepad++.exe).
07
Comportement : « Installer pour le système si la ressource est un périphérique ».
08
Clic droit → Déployer → définir regroupement cible et point de distribution.
09
Choisir Obligatoire (auto) ou Disponible (Centre Logiciel). Configurer planification et alertes.
✅L'application est publiée dans la bibliothèque SCCM.
BApplication MSI
01
Bibliothèque de logiciels → clic droit Applications → Créer une application.
02
Type : Windows Installer (*.msi) → indiquer le chemin réseau UNC.
03
Vérifier les informations auto-détectées, ajuster si besoin, puis Fermer.
CSupprimer un déploiement
01
Bibliothèque de logiciels → Gestion des applications → Applications.
02
Sélectionner l'app → onglet Déploiements → sélectionner le déploiement.
03
Ruban → Déploiement → Supprimer.

Configuration Master Windows 11
MDT — Microsoft Deployment Toolkit
Prérequis
Windows Server + WDS & MDTISO Windows 11Réseau DHCPPoste de référenceDroits admin
01Préparation du serveur MDT
1
Ouvrir le Deployment Workbench → créer une Deployment Share (ex : D:\DeploymentShare).
2
Clic droit → Operating Systems → Import Operating System → Full set of source files → pointer vers l'ISO ou le .wim.
3
Clic droit → Task Sequences → New Task Sequence → Standard Client Task Sequence → sélectionner l'image.
02Bootstrap.ini & CustomSettings.ini
[Bootstrap.ini] DeployRoot=\\SRV-WDS\DeploymentShare$ UserID=MasterOPH | UserPassword=P@ss123 | UserDomain=MASTER SkipWelcome=YES | KeyboardLocalePE=040c:0000040c
[CustomSettings.ini] OSInstall=Y | SkipCapture=NO | SkipAdminPassword=YES SkipProductKey=YES | SkipBDDWelcome=YES | SkipTaskSequence=NO SkipUserData=YES | SkipBitLocker=NO ComputerBackupLocation=\\SRV-WDS\DeploymentShare$\Captures EventService=http://SRV-WDS:9800
03Générer le WinPE & configurer WDS
1
Clic droit sur le Deployment Share → Update Deployment Share → génère Boot\LiteTouchPE_x64.wim.
2
WDS → Boot Images → Add Boot Image → sélectionner LiteTouchPE_x64.wim → activer pour démarrage PXE.

Capture Master Windows 11
MDT — Sysprep & capture WIM
Prérequis
SRV WDS (ADDS)SRV DHCPSRV MDT configuré
01Préparer la machine de référence
1
Installer Windows 11 23H2 sur une machine de référence (physique ou VM).
2
Configurer le système selon les besoins. Nettoyer les fichiers temporaires et applications inutiles.
02Créer la Task Sequence "Sysprep and Capture"
1
Console MDT → nouvelle Task Sequence avec le modèle « Sysprep and Capture ».
2
Vérifier que DeploymentShare$ est accessible en lecture/écriture depuis la machine de référence.
03Lancer la capture
1
Accéder à \\<serveur>\DeploymentShare$\Scripts → exécuter LiteTouch.vbs.
2
Le système exécute Sysprep, redémarre en WinPE et capture l'image .wim.
⚠️Résolution de problèmes courants
# BitLocker actif — déchiffrer manage-bde -off C: # Sysprep — AppxPackage Get-AppxPackage -AllUsers | Where PublisherId -eq 8wekyb3d8bbwe | Format-List Get-AppxPackage -AllUsers <NomPackage> | Remove-AppxPackage -AllUsers Remove-AppxProvisionedPackage -Online -PackageName <NomPackage>
✅Fichier .wim disponible dans : F:\DeploymentShare\Captures

Alerte espace disque insuffisant
Zabbix — Supervision et notification e-mail
01Créer l'Item
1
Configuration → Hosts → sélectionner l'hôte → Items → Create Item.
Name : Espace disque sur C: Type : Zabbix agent Key : vfs.fs.size[C:,free] Type : Numeric (unsigned) Units : GB | Interval : 1m
02Créer le Trigger
1
Triggers → Create Trigger. Severity : Warning ou High.
last(/NOM_HOTE/vfs.fs.size[C:,free]) < 10737418240 -- 10 Go = 10 × 1024³ octets
03Action & média Admin
1
Configuration → Actions → Create Action. Ajouter condition liée au trigger → Operations : envoi e-mail.
2
Administration → Users → Admin → Media → Edit → définir l'adresse e-mail de réception.
✅Vérifier que des alertes se génèrent sous le seuil et contrôler la réception e-mail.
